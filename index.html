About Me

I'm Matheus Vilano, a Game Developer based in Vancouver. My primary roles are Technical Design and Software Engineering, with a focus on audio behaviours, asset pipelines, gameplay systems, and development tools - I love multidisciplinary work.

Most recently, I shipped Baldur's Gate 3 and Moss: The Forgotten Relic. I also teach game development, where I've built courses on Unreal and Unity for both designers and engineers - teaching sharpened my communication and taught me the value of robust documentation early on.

In my free time I build open-source projects, like Wwise tools or Unreal plugins. My most popular FOSS project is PyWwise, a Wwise Authoring API wrapper for Python I still actively maintain. Anything at the intersection of arts, design, and engineering piques my interest - so for games, talks, and more, keep exploring!

PyWwise: WAAPI Made Pythonic

My most popular FOSS repository - a Wwise Authoring API wrapper for Python that I still actively maintain. 

# PyWwise Example
from pywwise import WwiseConnection, ELogSeverity, ELogChannel

with WwiseConnection() as ak:
    message = "Hello, Wwise!"
    severity = ELogSeverity.MESSAGE
    channel = ELogChannel.GENERAL
    ak.wwise.core.log.add_item(message, severity, channel)
