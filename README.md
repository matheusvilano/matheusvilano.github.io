# Matheus Vilano

This repository hosts Matheus Vilano's website, which contains his dev portfolio.

## Features

### Design
- **Dark, immersive theme** with neon purple/cyan/pink accents
- **Animated background** with grid pattern and floating particles
- **Glitch effects** on logo and typography
- **Glassmorphism** cards with backdrop blur
- **Gradient accents** throughout the interface
- **Smooth animations** and transitions

### Performance
- Vanilla JavaScript (no frameworks)
- Optimized CSS with CSS variables
- Lazy loading support
- Intersection Observer for scroll animations
- Debounced resize handlers
- Minimal external dependencies (only Google Fonts)

### Responsiveness
- Fully responsive design (mobile, tablet, desktop)
- Mobile hamburger menu
- Flexible grid layouts
- Touch-friendly interactions
- Optimized for all screen sizes

### Aesthetics
- HUD-inspired UI elements
- Tech grid background
- Particle system
- Parallax mouse movement effects
- Glitch animations
- Neon glow effects
- Gaming-inspired typography (Orbitron & Rajdhani fonts)

## Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --color-primary: #6366f1;      /* Purple */
    --color-secondary: #06b6d4;    /* Cyan */
    --color-accent: #f472b6;       /* Pink */
    --bg-primary: #0a0a0f;         /* Dark background */
}
```

### Fonts
Currently using Google Fonts:
- **Orbitron** - Futuristic display font
- **Rajdhani** - Clean body text
